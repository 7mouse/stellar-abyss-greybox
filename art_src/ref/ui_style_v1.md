# UI 样式规范 v1（已获制作人认可，2026-10-16）

参考图：/workspace/art/ui/hud_reference_v1.jpg

## 总体风格
- 高精度日系像素风，和游戏画面统一；画面整体方向：像素 + 死亡细胞式背景（暗底、亮色光源、层次剪影）。
- 界面克制：细像素线框 + 半透明深色底板，不用厚边框、圆滚滚的糖果按钮、花哨装饰（避免"廉价页游感"）。
- 不用水墨/毛笔质感。

## 配色
- 底板：炭黑半透明；线框/图标：米白
- 血量：猩红分段条；体力：青色细条
- 撤离/关键提示：青绿（全局唯一强调色）
- 战利品稀有度：灰 / 蓝 / 紫 / 金

## 战斗 HUD 布局
- 左上：方形像素头像 + 红色分段血条 + 青色体力条
- 右上：像素小地图（深色底，红色箭头标玩家，青点标撤离点）
- 底部中央：4 个技能格（细框方块，白色单色图标，右下角小三角表示冷却/可用）
- 技能格下方：青绿色撤离进度条（中间菱形标记）

## 角色比例（2026-10-16 制作人确认）
- 游戏内战斗像素小人：参考《泽诺尼亚》，约 2–2.5 头身（大头短身 SD），略俯 3/4 视角，高精度像素、清晰描边。
- 对话立绘/剧情：D 比例（约 6.5 头身，写实修长的日系动画风）。

## 定稿 v2（2026-10-16，制作人确认，取代上文像素风设定）
- 画风：非像素，日式手绘 2D。线条细而干净，软赛璐璐上色，背景偏绘画质感；用自然的低饱和色（苔绿、秋橙、灰石、青色传送门光）。
- 镜头：高俯视 3/4 视角，大地图开放探索；敌人散布在地图上，不排成一行（避免像回合制）。
- 比例：局内是约 2.5 头身的 Q 版，主角约占屏幕高度的 1/8（试过 2 头身更 Q 的版本，制作人选了 2.5）；对话立绘用 D 比例（约 6.5 头身）。
- HUD：左上是头像、HP/MP/SP 三条和等级；右上是层数、背包容量、碎片数、暂停键，下面是圆形小地图（青色箭头指向撤离点）；右下是大的攻击键，外面一圈弧形排着重攻击、冲刺和 2 个技能；左下是 1 个消耗品格。不放存档和计时，因为中途不能撤离。
- 边框细、克制，配色用炭黑、米白、绯红、青。
