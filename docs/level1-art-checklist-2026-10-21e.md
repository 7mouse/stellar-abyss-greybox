## 画质（看过 mock 之后的判断，诚实版）
- **比 21d 明显好**：画面有了前后层次（背景树丛 → 悬崖 → 地面 → 角色 → 前景树冠），不再是一片平地；石板路是不规则石块，看不出 512 网格；贴花沉进地面里，不再像贴纸；U16 九个图标是同一套画风（深色描边、Q 版），和角色一致。单看截图已经不像“页游素材拼盘”。
- **和 baseline 比还差的地方**：
  1. baseline 更暗、更有雾气和明暗对比（远处发蓝灰、近处有阴影），我们的画面整体偏亮、对比平，像白天的晴天；这是整体调色 / 光照的问题，单件改不了，建议程序侧加一层场景色调（暗角 + 远景雾）再看。
  2. baseline 的废墟和石块密度高很多，画面“满”；我们中间仍有一大片空草地。地标件（S10–S17）进来以后会好一些。
  3. 石板路是按 512 格子铺的，路两边是直线，baseline 的路是斜着、弯的。要弯路需要更多边缘 / 拐角件或者程序用遮罩混合。
  4. 悬崖面只有大约 1 个主角高，在大树旁边显得矮；悬崖段之间的接口是原图自然断口，拼的时候要重叠。
  5. 树冠边缘有零星 1–2 px 的白点（白底抠图残留），1080p 下近看能看出。
  6. HUD 纸纹很淡（0.08），远看几乎还是平的；如果要更“手绘”，可以把强度提到 0.12–0.15，但再高就会脏。
- **AI 味**：最明显的是背景树丛和前景树冠（同一张原图两种颜色，重复用时能认出来），以及悬崖草皮上沿是一条很直的水平线。其他件和 baseline 是同一个语汇。
