# 骨骼动画拆件规范 v1（给美术）

适用于第一关的主角、发芽野猪、根须孢子菇、史莱姆、层守·苔冠王野猪。程序在 Godot 里用 Skeleton2D 绑骨骼、K 动画。美术交拆好的部件图和参考动作。

## 1. 交付物（每个角色一套）
1. **分层源文件 PSD**：每个部件一个图层，按下面的命名规则命名，各部件摆在拼好的站姿位置上（程序直接按图层坐标拼装）。
2. **拼好的整图预览 PNG**：和 PSD 同尺寸，用来对照。
3. **参考动作**：每个动作给 2 到 4 张关键姿势草图，或者一段很短的参考视频或 GIF，标出节奏，例如“蓄力 0.3 秒，挥出 0.1 秒”。
4. **枢轴点标注**：在 PSD 里单独放一个 `_pivots` 图层，每个关节点一个小圆点，旁边标上部件名。

## 2. 画布与比例
- 画布按负责人定的尺寸：主角、发芽野猪、根须孢子菇各 256×256，史莱姆 256×192，层守·苔冠王野猪 320×320。
- 按游戏内 1:1 绘制，不要画大了再缩，也不要放大。
- 角色脚底中点放在画布底边往上约 8% 的位置，四周留出动作空间（挥砍、跳起来）。
- 背景透明，PNG 32 位，边缘不要有白边或黑边。

## 3. 朝向
- 每个角色画 3 套：正前、正后、右侧。左侧由程序镜像。
- 史莱姆几乎是圆的，只画 1 套朝右即可。
- 3 套之间的部件尽量共用，例如武器、尾巴；不能共用的部件，加后缀 `_f`、`_b`、`_s` 区分。

## 4. 拆件原则
- **一个能独立转动的部位就是一个部件。** 关节处要有重叠：两个部件在关节处各多画 10 到 20 像素，转动时才不会露缝。重叠部分画成完整的圆头，不要直接切平。
- **被遮挡的地方也要画完整。** 例如被手臂挡住的身体侧面、被头发挡住的后脑。转动时会露出来。
- 部件数量控制在 15 个以内（层守 20 个以内）。不需要动的细节合进所属部件，不单独拆。
  - 注：主角的背包（`backpack_b`、`backpack_s`）不计入 15 个的上限（第 11 节确认的例外）。
- 需要弯曲变形的大块部件（例如身体、斗篷、野猪背部）单独拆，并在图层名后加 `_mesh`，程序会给它做网格权重。
- 眨眼、表情、嘴型做成可以切换的替换图（同一位置的多张图），例如 `eye_open`、`eye_close`。

## 5. 各角色建议拆分
| 角色 | 部件 |
| --- | --- |
| 主角 | 头、头发前、头发后、围巾（_mesh）、身体（_mesh）、上臂 L/R、前臂+手 L/R、大腿 L/R、小腿+脚 L/R、武器、眼睛（开/闭） |
| 发芽野猪 | 头（含獠牙）、头顶芽、耳 L/R、身体（_mesh）、前腿 L/R、后腿 L/R、尾巴、眼睛（开/闭） |
| 根须孢子菇 | 菌盖、菌柄身体（_mesh）、根须 L/R（各 2 段）、眼睛（开/闭）、嘴（闭/张，吐孢用） |
| 史莱姆 | 身体（_mesh，压扁和弹起全靠它）、高光、眼睛（开/闭）、嘴 |
| 层守·苔冠王野猪 | 苔冠、头、獠牙 L/R、耳 L/R、鬃毛（_mesh）、身体（_mesh）、前腿 L/R（各 2 段）、后腿 L/R（各 2 段）、尾巴、眼睛（开/闭/怒） |

L 和 R 以角色自身的左右为准。

## 6. 命名规则
- 全部用小写英文加下划线：`部位_左右_朝向`，例如 `arm_upper_l_f`、`leg_lower_r_s`、`body_mesh_b`。
- 不同朝向的同名部件，结构和图层顺序要一致。
- 图层顺序就是前后遮挡顺序，最上面的图层最靠前。

## 7. 动作清单（参考动作要覆盖）
| 角色 | 动作 |
| --- | --- |
| 主角 | 待机、移动、轻攻击三连、重攻击、冲刺、技能、受击、倒下 |
| 发芽野猪 | 待机、移动、冲锋（含蓄力）、撞击、受击、倒下 |
| 根须孢子菇 | 待机、移动、吐孢（含蓄力）、受击、倒下 |
| 史莱姆 | 待机（呼吸起伏）、移动（一弹一弹）、扑击、受击、倒下（化开） |
| 层守·苔冠王野猪 | 待机、移动、冲锋、践踏（范围攻击）、召唤或吼叫、受击、二阶段变身、倒下 |

## 8. 交付方式
- 放到 `/workspace/art/rigs/<角色名>/`，每个角色一个文件夹，内含 PSD、预览 PNG 和参考动作。
- 文件名带版本号，例如 `hero_parts_v1.psd`。改稿时升版本，不覆盖旧文件。

## 9. 交付前自查
- [ ] 每个部件在单独的图层上，命名正确。
- [ ] 关节处有重叠，被遮挡的部分画完整了。
- [ ] 有 `_pivots` 图层，每个关节都标了点。
- [ ] 画布尺寸、脚底位置、透明背景都正确。
- [ ] 3 个朝向都有（史莱姆 1 个）。
- [ ] 参考动作覆盖了第 7 节的清单。

## 10. 第一批先交
先交主角和发芽野猪。程序先拿这两只验证骨骼和动画管线，确认拆法没问题后，再交其余三只，这样返工最少。

## 11. 补充约定（2026-10-16，回复美术 6 个问题）
- **源文件尺寸**：源文件按 2 倍尺寸画，交付时导出成 1:1。下面所有像素数都是 1:1 下的数值。
- **关节重叠**：小部件（前臂、小腿、手、耳、尾巴等，宽度 ≤ 20px）重叠 4–8px；大部件（身体、大腿、头）仍是 10–20px。
- **斜向朝向**：只要有水平分量就用侧面（右侧，左边镜像）；只有纯上、纯下用背面和正面。程序加 15° 的缓冲，避免在边界附近来回切换。
- **空图层**：可以保留，导入工具会跳过空图层，不需要放 1px 像素。
- **调色**：程序做调色 shader。美术每个角色交一条源色板（8–16 个颜色，PNG 横条），换色版再交一条同样长度的目标色板即可，不用另画整套换色图。描边色和高光色也放进色板。
- **网格变形**：_mesh 部件的拉伸和压缩控制在 15% 以内。史莱姆压扁是例外，最多 25%。
- **背包**：拆成独立部件 `backpack_b`（背面）和 `backpack_s`（侧面），挂在身体骨骼上整块刚性跟随，不参与变形；正面看不到就不用画。

## 12. AI 直出素材的宽容处理（制作人定，2026-10-16）
美术素材先全部用 AI 直接生成，不做手修，部件接缝和边缘可能不干净。程序这边这样兜底：
- 导入时自动清理：去掉半透明的杂边（alpha 低于阈值的像素直接清掉），把孤立的杂点删掉。
- 关节处默认多盖一点：程序会给关节加一块和部件同色的圆形垫片，或者让部件自动外扩几像素，挡住接缝。
- 整个角色统一套一层描边 shader，盖住锯齿和不齐的边缘，描边颜色从色板里取。
- 拆件和命名规范照旧，这样以后换成干净的素材时，不用改动画。
- 发芽野猪的素材放在 art/rigs/sprout_boar/，代码里的 id 仍是 mushling。
